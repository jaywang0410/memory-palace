# 基于loona aap的样式修改的的记忆方案
一个为 AI 伴侣与主人共同记忆打造的沉浸式交互空间。从温馨的 2D 居家房间到治愈系记忆星空，让每一段对话都能被珍藏和看见

> **Live Demo**: 本地运行 `npm run dev` 即可体验

## 核心概念

- **短期记忆** → 存在于温馨房间中，通过实时对话和事件自然积累
- **长期记忆** → 当主人说"存到长期记忆"或每晚自动飞升，化作星空中的永恒星辰
- **记忆生命周期**: 对话积累 → 水晶球汇聚 → 飞升动画 → 星空新生

## 功能特性

### 房间场景
- **2D 插画背景** - 温馨居家风格，可交互热点
- **实时对话** - 右下角浮动聊天窗口，支持文字输入 + 语音输入（Web Speech API）
- **记忆收集器** - 右上角水晶球，短期记忆越多光芒越亮，点击查看今日记忆
- **日记本** - 翻页查看最近 7 天的日记记录
- **家具交互** - 书架、电视、音响、电脑等热点，点击弹出专属内容
- **夜间模式** - 开启后房间进入月光氛围，天窗可进入星空（暂时这么做，可以改成只有真实的晚上才能进入，且是互动了达到一定次数之后）

### 星空场景
- **五大星座区域** - 日常、情感、旅行、成长、人际
- **核心星星** - 中央金色星辰 LOONA & FRIYA，代表 AI 与主人的羁绊
- **星星关联** - 相关记忆自动建立连线
- **交互操作** - 滚轮缩放、拖拽平移、点击星星查看详情

### 记忆系统
- **统一记忆层** - 所有记忆统一数据结构，区分短期/长期状态
- **自动关联** - 基于场景、人物、情感、星座自动计算记忆关联度
- **星座分配** - 飞升时根据内容关键词自动分配星座区域

## 使用指南

### 体验完整流程

1. **打开房间** → 看到温馨居家场景
2. **点击右下角 💬** → 与 loona 聊天，每条对话自动存入短期记忆
3. **观察右上角水晶球 🔮** → 记忆越多光芒越亮
4. **发送"存到长期记忆"** → 触发飞升动画，记忆化作光点飞向星空
5. **自动切换星空** → 看到新诞生的星星出现在对应星座区域
6. **点击星星** → 查看珍贵回忆详情

### 快捷键 / 操作

- 点击家具热点 → 打开对应功能
- 点击 ✨ 天窗 → 切换夜间模式
- 夜间模式下点击"深潜入星河" → 进入星空
- 星空点击星星 → 查看记忆详情
- 滚轮 → 缩放星空
- 拖拽 → 平移星空

## 自定义数据

记忆数据位于 `src/data/` 目录：

- `diaryMockData.ts` - 日记演示数据（30天）
- `starMemories.ts` - 星空记忆数据（45颗）

修改这些文件即可替换为你自己的记忆内容。统一记忆类型定义在 `src/types/memory.ts`。
